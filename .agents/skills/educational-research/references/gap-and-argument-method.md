# Bounded gaps and independent author arguments

Compare 3–10 closest studies: what already exists, exact missing mechanism/context/population/method/theory integration, supporting evidence, theoretical consequence, search boundary, method-fit and novelty boundary. Merely changing population or renaming a construct does not establish a meaningful gap. Use well/provisionally supported or speculative confidence; the automated gate never guarantees originality or exhaustive coverage.

Construct 3–7 main claims when evidence warrants them, not to fill a quota. Each claim needs source IDs, evidence IDs (`source:segment`), warrant W..., objection O..., qualification, confidence and dependencies. Use two independent sources where possible. Retain contradictions as explicit graph edges; do not average them into consensus. Make a coherent thesis plus introduction/literature review/method-fit/discussion alignment map. Methods-fit is advisory without actual data/design.

Argument-led paragraph plan: target author's claim → source A evidence → source B alignment/tension → critical comparison → mechanism/warrant → boundary/rival explanation → contribution/transition. Keep source author's words and target writer's inference visibly distinct.

Audit unsupported/overstated claims, evidence mismatch, indirect citations posing as primary evidence, scope drift, obsolete RQs, theoretical overload, construct inconsistency, normative/empirical confusion and proposed research presented as observed results. CLI lexical warnings are only a first-pass aid. `revise` requires surgical, source-traced edits that preserve the user's voice and structure; the CLI supplies a line map rather than a misleading automatic rewrite.
