# v2 prospective protocol

SearchProtocol is written before native requests. Supply an agent-refined `--protocol` JSON containing problem, 1–3 candidate RQs/focal RQ, competing explanations, population/stage/setting/geography/period, constructs/outcomes/intervention, study types/language, eligibility and scope justification, keyword clusters/descriptors, British/American alternatives, seminal/contrary evidence and citation-chaining plan. Broad topics generate explicitly provisional dimensions, not invented facts about the user.

Preserve actual preparation time and amendments. On resumed/imported discovery use the original protocol; a timestamp created after the searches does not prove prospective search design. The engine logs exact executed queries/filters/IDs/counts/errors and screening/exclusions. Source access, actual scope coverage and method-quality judgements remain distinct from metadata enrichment and lexical ranking.
