# Educational Research / 教育研究

Deliver one clean `Research_Roadmap.pdf` and a one-paragraph note. Complete editable acquisition, evidence and quality records remain in private `evidence/`. Use the companion Python package (`python -m pip install -e .`). Follow the user's language; default academic prose is British English. A manuscript word target sizes discovery, never automatically commissions an essay. Scientific accuracy and a defensible negative conclusion take precedence over an attractive gap claim.

## Preserve the user's quantity

A topic alone targets **at least ten** distinct, relevant, deeply reviewed scholarly works. Explicit N overrides the word-count heuristic: “20 papers/20篇文献” maps to `--target-references 20`; exact is the explicit-count default, and “at least/至少” adds `--source-semantics at_least`. Preserve the exact request with `--user-quantity-intent`. The agent interprets chat; the CLI does not parse it magically. Without explicit N, use ceil(target_words/100), floor ten; ten is not a cap. Strict acceptance requires max(10,N,any higher expressly required reading count). Ten full texts plus ten abstracts never satisfies twenty. Keep selected works, qualified readings and public excerpts as separate factual counts.

## Native research workflow

1. **Scope and discover.** Follow [protocol](references/research-protocol.md) and [ERIC/Scholar](references/eric-and-google-scholar-search.md). Define the focused problem/RQ, constructs, context, rivals and eligibility prospectively. Search broadly within a logged budget. Actual ERIC receipts and lawful dated Scholar observations are required; a plan or metadata enrichment is not an executed Scholar search.
2. **Acquire lawful full text.** Read [full-text access](references/full-text-access.md). Native online `--full-text-mode auto` attempts bounded public publisher/ERIC/repository/OpenAlex/DOI-Unpaywall/CORE paths; no institutional subscription is inherited. Retrieval, content completeness, legal processing, version and close reading are different states. A DOI, OA pointer, abstract, landing page or download never establishes that a paper was read. Stop denied/CAPTCHA/restricted paths; use the private access handoff. Never solicit passwords or bypass access restrictions.
3. **Read and explain originals.** Use [full-text reading](references/full-text-reading.md) and [quotation policy](references/source-evidence-and-quotation-policy.md). Read the actual lawful work or justified theoretical chapter. Record at least four distinct checked anchors: thesis/definition; method/mechanism; finding/reasoning; limitation/counterevidence. Each needs exact private span, locator, context, attributed paraphrase, warrant, evidence kind, qualification and distinct own inference, plus version/hash/reader/date and permitted processing scope. Use `assets/source.schema.json`. Each source independently needs >=100 English words of useful anchored explanation in the reader, normally 100–140; titles, metadata, citations, quotes and our inference do not count. Never pad 75 verified words into 100: retain the useful short explanation as PROVISIONAL and report its exact shortfall privately.
4. **Integrate and challenge.** Use [argument/gap method](references/gap-and-argument-method.md). Build 3–5 connected comparative chains, each with at least two independent qualified readings, actual source positions, different checked anchors, warrant, counterargument and separate qualified synthesis. Compare 5–10 closest works and the strongest gap-destroying rival. A refuted or unsupported gap calls for a revised question, not a new selling point. Preserve actual negative/null evidence.
5. **Explain and plan.** Read [framework](references/framework-builder.md) and, if empirical, [feasibility](references/study-design-feasibility.md). Compare 2–3 lenses privately; show the selected parsimonious lens and one connected figure. Define each construct and link through source claim/gap/RQ/measure or code/analysis/contribution, including disconfirming evidence. QUAN/QUAL must have distinct legitimate questions and integration; unknown access or unavailable non-users requires an explicit feasibility gate and honest fallback.
6. **Render and inspect.** Resume the native pipeline with audited `--sources`, `--synthesis`, original `--protocol` and `--discovery-records`. Read [reader model](references/roadmap-reader-view.md), [output contract](references/compact-pdf-output-contract.md) and [quality gates](references/research-quality-gates.md). Preserve approved A4 monochrome Times geometry and inspect actual first/evidence-dense/framework/middle/final previews. The PDF has five sections: research logic; what authors establish; argument integration/closest-study challenge; framework/roadmap; APA references. No visible search errors, scores, hashes or gate/matrix dumps. Legacy `--presentation evidence-pack` and explicit `--include-audit-pdf` remain available.
