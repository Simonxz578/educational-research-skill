# Primary evidence, distinct inference and conservative reproduction

Read the lawfully available original work/version in context. Preserve source author position, source method/evidence/warrant and the researcher's own use as distinct layers. A DOI, metadata record, publisher abstract or accessible teaser is not a full-text reading. Exact minimal private spans need matching artifacts, native locators and verified source/version/hash; quotation marks never turn a paraphrase into an author's words.

The 100-English-word per-source requirement concerns useful anchored EXPLANATION, normally 100–140 words, not reproduction. Count the four checked source paraphrases actually rendered, excluding title/bibliography/citations/locators, quotes, generic context and independent inference. Never average or pad. Four different anchors must carry different meaning; 150 repetitive or unsupported words fail. A shorter verified explanation remains honestly provisional.

Default aggregate reproduced source wording is <=20 words per copyrighted work across the entire reader PDF, including repeated declared fragments in paraphrases, synthesis or other sections. This is conservative internal project policy, not a universal statutory entitlement or a 100-word copying allowance. Larger reproduction requires independently verified licence/permission provenance and actual applicable scope. A user-supplied PDF permits neither automatic hosted-AI processing nor onward publication. Keep private exact spans private. Legacy 25-word inputs may load in compatibility mode but do not automatically meet the current substantive policy.

Embed one or two short, informative, authentic source-language fragments where quotable, with accurate punctuation/omissions and known locators. Avoid quote accumulation. Verify each fragment against the actual lawfully held version; AAM text does not inherit unavailable VoR pages. Label user/published translations separately. With no-reproduction rights, use faithful traceable paraphrases and an honest zero-excerpt count. If quotation or processing scope cannot be verified, leave the appropriate status incomplete; do not invent wording or rights.

Qualitative reports are not prevalence; association is not causation; aspirations/confidence/intentions are not observed behaviour; proposed benefits are not tested outcomes. Keep source qualifications, negative cases and inference limits attached to the exact claim. No paywall/CAPTCHA bypass, credential borrowing, shadow libraries or unauthorised bulk download. Public Git contains no source PDFs, licensed full text, real observation logs, private manuscript/student data or credentials; preview PDFs are prominently synthetic TEST ONLY.
