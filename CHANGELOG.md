- Add versioned deep-reading records, lawful full-text artifact hashes, substantive passage/locator checks and reading audits. Metadata and legacy access flags never promote themselves to deep reading.

- Add literature-led framework schemas, candidate-lens selection, bounded constructs, mechanisms, disconfirming patterns, editable diagram JSON/Mermaid/SVG and construct/RQ/evidence/method alignment/drift audit.
- Add conditional QUAN/QUAL/integration/feasibility checks and anchored, explicitly reviewable editorial assessments.
- Preserve all 15 matrix groups and original artifact aliases. Add native CLI/renderer receipts, artifact sealing, independent gate recomputation, readable-type/link checks and versioned visual-review records.
- Extend bilingual skill guidance, schema/migration documentation and synthetic negative regressions. Native examples use the real CLI; no protected full texts, user research notes or fonts are published.

See [v2 usage and migration](docs/QUALITY_ENGINE_V2.md) and [observed validation results](docs/V2_VALIDATION.md). Publishable quality remains an aspirational standard, never a claim of journal acceptance or replacement for primary reading and expert review.
