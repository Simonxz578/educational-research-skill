# Verbatim inspection, abstract fallback and scope (v0.4.3)

The private full-text gate counts >=100 non-overlapping English word positions matched to the actual attached original version across four meaningful roles. It does not require 100 unique vocabulary items and does not count paraphrases. Canonical NFKC/punctuation/whitespace reconciliation does not permit invented words. Repeated, ambiguous or overlapping spans, source mixing, mismatched identity/version/digests, title/metadata/references and absent text fail verification. Native span ledgers preserve source/version/URL, artifact and extraction hashes, locators, canonical start/end offsets, attributed claim, reader/date/scope and separate usage decisions. Actual meaningful interpretation remains an expert judgement.

Keep VERBATIM_PRIMARY_TEXT / SOURCE_ANCHORED_EXPLANATION / OUR_INTERPRETATION typed separately, with separate counts. Explanation has no arbitrary minimum. Public quotes must actually match original text; explanation is explicitly labelled as explanation/paraphrase, never “the author's original 100 words”.

Verified published abstracts are legitimate included reader sources when full text or its processing is unavailable. Prefer publisher metadata, then authentic Crossref/ERIC abstracts with exact publication identity, actual URL/artifact/digests and permitted processing/retention. Unverified abstract strings or DOI metadata alone are not eligible. Native fallback is bounded and automatic; the agent reads available abstracts and supplies checked faithful explanations without asking the user to fix each paper. Missing methods/results/limitations stay unknown. Reader label ABSTRACT ONLY and locators remain published-abstract locators. No four deep anchors are fabricated and the full-text 100-word gate is NOT APPLICABLE TO ABSTRACT / NOT FULL-TEXT VERIFIED. No actual abstract means METADATA ONLY privately.

Track included N, FULL_TEXT_VERIFIED K, ABSTRACT_ONLY A and unfilled requested-item shortfall independently. Strict G2 still needs max(10,N,higher requested reading threshold) deep full-text reviews. Thirteen full texts plus seven abstracts is twenty items/references, with a seven-work full-text shortfall. Abstracts may support explicitly preliminary comparisons but cannot prove an unqualified full-text conclusion or novelty. Five reader sections and the approved monochrome geometry stay unchanged.

Source access, processing, private retention and public quotation are separate rights decisions. Private inspection does not license public reproduction. Default aggregate public quotation remains <=20 source words per work, including repeats in arguments/framework, unless verified licence/explicit permission supports more. Unknown public quotation rights means no quote: use a faithful explanation/link. Never reproduce an entire protected abstract by default or put the private span ledger in the reader. Public examples contain generated TEST ONLY material exclusively.
