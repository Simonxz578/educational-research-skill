# Literature-led conceptual / theoretical framework

Use Framework in the native synthesis schema; the CLI validates/renders, the agent does the reasoning. Do not manufacture theory names from topic keywords.

1. Extract phenomenon, outcomes and proposed mechanisms from the RQ and strongest deeply read content. Consult [Jabareen (2009)](https://doi.org/10.1177/160940690900800406), publisher full text checked 2026-10-29: conceptual framework construction connects and revises concepts through iterative interpretative analysis; it is not automatically a predictive model.
2. Compare plausible traditions (normally 2–3 where literature supports them) on explanation, epistemology, scope, evidence, operationalisation and method fit. Choose a primary lens or justify a parsimonious combination/no-single-theory synthesis. Name rejected/secondary alternatives and reasons. A list of fashionable lenses is not explanatory work.
3. Define constructs with cited passages and boundaries. State near-synonym distinctions instead of replacing aspirations with goal clarity, formal access with capability, or capability with attendance. Non-use may reflect choice; infer exclusion only with evidence. These are examples of a general boundary problem, not a preset framework.
4. Link constructs via mechanisms, conditions, moderators/mediators/feedback only where warranted. Source-verified, hypothesised and interpretative sensitising links remain distinct. A direction arrow never establishes causal identification; a causal link requires an explicit identification argument.
5. Map each construct to RQ, claim, evidence, proposed measure/interview code/document indicator, analysis, expected and disconfirming pattern. Record uses across title/purpose/RQ/theory/measurement/coding/analysis/claims/policy, with evidence-led bridges for altered labels. The automated drift audit flags location-specific substitutions; semantic adequacy still needs review.
6. Explain existing theory's failure, modest conceptual contribution, scope and evidence that would revise the model. The lens must affect sampling, measurement, analysis or interpretation. Unused lenses fail theory-fit.

Native outputs: Theoretical_Conceptual_Framework.json; Framework_Diagram.json, Framework.mmd and editable SVG; Theory_RQ_Evidence_Method_Alignment.csv; Framework_Audit.json. Native PDF includes vector diagram, legend, definitions, alternative lenses, mechanism/boundary tables and alignment. Keep node labels and model complexity readable; do not shrink type or turn an exploratory capability interpretation into a causally identified regression model.
