The v0.2 pipeline, models, gates, renderer, CLI, schemas and tests were inspected before changes. The baseline offline suite passed (47 tests plus one deliberate live skip). The user-provided three-page preview was inspected as a private visual reference only: its personal/topic content is not a fixture or public asset. Public house geometry and licence provenance remain separately documented.
