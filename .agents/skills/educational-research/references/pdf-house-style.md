# Academic house style

Measured/adapted from https://github.com/Simonxz578/personalised-practice-generator commit 0f658aa0f7f6da8c072bcf596db06248aa59adbe, v0.4.0. Inspected SKILL.md, references/pdf-style-guide.md, assets/pdf-reference-style.json, assets/style-reference/README.md, scripts/render_pdfs.py, scripts/inspect_pdf.py and public sample PDFs. This renderer is an independent academic adaptation; exam content/marks/answer keys are not carried over.

A4 portrait; left 56.7 pt; right edge 538.6 pt; content top 56.7 pt and bottom 48.2 pt. Running thin rule 42.5 pt from top, page number centred at 27 pt from bottom. White/black/grey only. Title 18, sections 12, body 10.5/14, matrix 9.5/12 pt. Flow pagination, repeated source headers and readable multi-line subrows. Preserve full DOI URLs and hanging reference indents.

Load licensed installed Times New Roman or Liberation Serif; never redistribute fonts. CJK uses ReportLab's STSong-Light CID font reference (viewer font support required), with source-language text preserved. Missing unsupported characters fail clearly rather than silently disappearing. Prefer an embedded licensed CJK font in a customised renderer for archival CJK publishing.
