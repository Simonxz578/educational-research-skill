# ERIC + Google Scholar

Verified 2026-10-29: ERIC homepage footer API → https://eric.ed.gov/?api → Swagger schema https://eric.ed.gov/api/eric-api.yaml. The documented GET endpoint is https://api.ies.ed.gov/eric/ with `search`, `format`, `start`, `rows` (max 2000), and `fields`. Phrase queries use fields such as `subject:"Reading Comprehension"`; peer review is `peerreviewed:T`. `publicationdateyear`, `educationlevel`, `identifiersgeo`, `publicationtype`, `language`, `id`, `sourceid` and `e_fulltextauth` retain context. The schema explicitly says a future Thesaurus API may be provided: do not invent one. Browse https://eric.ed.gov/?ti=all to check descriptor vocabulary; record assigned subject terms and expand.

Default CLI runs bounded general, theory and recent evidence queries. Add `--descriptor`, `--education-level`, `--geography`, dates and `--peer-reviewed`; manually assess completeness and log expansions. ERIC indexing and peer review do not prove methodological strength.

Google Scholar https://scholar.google.com/intl/en/scholar/help.html supports exact title/phrase, author, date and publication filters; Cited by, Related articles, All versions and export. Use an authorised interactive browser/manual route, or a genuine user-provided export. No bulk scraper, unofficial API, identity spoofing or CAPTCHA bypass. This package has no Scholar network scraper.

When unavailable write exact query links, status GOOGLE_SCHOLAR_NOT_CHECKED and SCHOLAR_MANUAL_PLAN_ONLY. CSV import requires `title,url,query,observed_at`, optionally `authors` (semicolon-separated), `year,cited_by`. Imported observations are SCHOLAR_USER_EXPORT_IMPORTED, user-attested, not independently verified. The CLI never emits SCHOLAR_SEARCHED_VERIFIED without browser evidence. Retain browser observations privately with dates, titles, URLs, query/filter and visible citation counts. Never infer citation counts.

Crossref https://www.crossref.org/documentation/retrieve-metadata/rest-api/ and OpenAlex https://help.openalex.org/api/ are secondary identity/metrics services. Cite their actual indexes. Keys use environment variables, never committed configuration. Current OpenAlex authentication https://help.openalex.org/api/authentication/ allows basic keyless use; substantial work may need a free key and service limits can change. Respect 429 and long Retry-After; resume cached batches later. Do not claim publisher VoR or retraction checks from Crossref-only matching.
